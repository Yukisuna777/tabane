# Tabane 束ね

**エージェント監督特化ターミナル。** 1画面をペイン分割して複数の Claude Code / codex / CLI を並べ、各ペインに自由入力のタイトルを付けて、返事待ちになったペインが光って分かる Electron アプリ。

複数のAIエージェントを並行で走らせると「どれが入力待ちか」を目視巡回する羽目になる。Tabane は **並べる・名札を付ける・待ちが光る** の3点に特化して、その認知負荷を下げる。

> ⚠️ 開発初期（MVP）。動作確認が取れるまで private。

## 特徴（MVP）

- 🪟 **1ウィンドウ内のペイン分割** — 縦/横に自由分割、ドラッグでリサイズ、クローズ
- 🏷 **固定タイトルバー** — 各ペイン上部に自由入力の名札。「どのプロジェクトのエージェントか」が一目で分かる
- 🔔 **返事待ち検知で発光** — エージェントが入力待ちになったペインの枠が光り、ステータスドットが点滅。フォーカスすると消灯
- 🌏 日本語UI

## 技術構成

| 層 | 技術 |
|---|---|
| ガワ | Electron 33 + electron-vite |
| UI | React 18 + TypeScript |
| 端末描画 | @xterm/xterm（WebGL レンダラ） |
| PTY | node-pty（main プロセス） |

返事待ち検知は main プロセス側で行い、非フォーカスのペインでも動く。BEL / デスクトップ通知系 OSC シーケンスを一次シグナル、出力静止タイマーを補助シグナルにするハイブリッド方式（しきい値は暫定、実運用でチューニング）。

## 開発

```bash
npm install      # node-pty を Electron 向けに自動リビルド（postinstall）
npm run dev      # 開発起動
npm run build    # ビルド
npm run typecheck
```
